## Introducción

La Inteligencia Artificial está transformando la forma en que diseñamos, desarrollamos y mantenemos sistemas software. Sin embargo, la mayor parte de la formación actual se centra en aprender herramientas concretas o en dominar tecnologías que evolucionan constantemente.

Este proyecto nace con un objetivo diferente.

No pretende enseñar únicamente a utilizar un modelo de lenguaje, un agente o un framework. Pretende definir una forma de trabajar.

Su propósito es construir una metodología de **Ingeniería y Arquitectura Asistidas por Sistemas Inteligentes**, donde la Inteligencia Artificial sea un colaborador del ingeniero y no un sustituto de su criterio.

---

## Objetivos

Los objetivos del proyecto son:

* Comprender en profundidad las tecnologías que forman el ecosistema actual de la IA.
* Experimentar mediante laboratorios prácticos y casos reales.
* Documentar sistemáticamente cada experimento, decisión y resultado.
* Identificar patrones, buenas prácticas y anti-patrones.
* Extraer principios generales aplicables a cualquier tecnología.
* Definir una metodología reproducible para el desarrollo de soluciones asistidas por Sistemas Inteligentes.

El objetivo final no es aprender una herramienta.

El objetivo final es aprender **una forma de hacer ingeniería**.

---

## Filosofía

Este proyecto se basa en una idea sencilla:

> **No se construye una metodología desde un despacho. Se descubre mediante la práctica.**

Cada laboratorio, cada error y cada decisión forman parte del conocimiento del proyecto.

Ese conocimiento se documenta, se analiza y, posteriormente, se transforma en principios y procesos reutilizables.

---

## Método de trabajo

Cada tema seguirá un ciclo común:

1. Estudio de los fundamentos.
2. Desarrollo de laboratorios.
3. Análisis de resultados.
4. Documentación.
5. Identificación de patrones.
6. Revisión crítica.
7. Incorporación del conocimiento a la metodología.

De esta forma, la metodología no se escribe antes de comenzar.

La metodología **emerge** del trabajo realizado.

---

## Principios

El proyecto se apoya en varios principios fundamentales:

* El pensamiento crítico siempre prevalece sobre la automatización.
* La IA asiste al ingeniero; no decide por él.
* Toda decisión debe poder justificarse.
* Todo experimento debe dejar conocimiento reutilizable.
* La documentación forma parte del producto.
* Las herramientas cambiarán; los principios deben permanecer.

---

## Resultado esperado

Al finalizar el proyecto no solo se habrá adquirido conocimiento sobre Inteligencia Artificial.

Se dispondrá de:

* una colección de laboratorios documentados;
* un catálogo de patrones y anti-patrones;
* una base de conocimiento reutilizable;
* y una metodología de Ingeniería y Arquitectura Asistidas por Sistemas Inteligentes, construida y validada mediante la práctica.

Ese será el verdadero resultado del proyecto.

---

## Ecosistema

Este proyecto se desarrolla sobre un ecosistema de ingeniería en el que cada herramienta aporta capacidades específicas dentro del proceso de diseño, desarrollo, experimentación y documentación.

| Área | Herramientas |
|------|--------------|
| Lenguajes | Java · Python · C++ · Bash · R (Documentación) |
| IDE | VS Code |
| Documentación | Quarto · Markdown |
| Publicación | GitHub · netlify |
| Diagramas | PlantUML |
| Bases de datos | MariaDB (SQL) |
| Entornos reproducibles | Docker |
| Laboratorios | VirtualBox · Hyper-v |
| Sistemas Inteligentes | ChatGPT · Claude · Ollama · Copilot · Continue |
| Automatización | MCP · Agentes · Skills · Open Specifications *(según evolucione la investigación)* |
